## 1. 주제와 핵심 컨셉

- 주인공은 기억을 **잃은 것**이 아니라, 자신의 죄를 외면해 **기억하지 못하게 된 것**이다.
- 플레이어는 단서를 모아 **기억을 추리로 재구성**한다. 이 과정에서 주인공의 마음이 만든 **왜곡된 선택지**가 섞여 나오고, 그것을 고르는 행위 자체가 "외면"이 된다.
- 주인공의 과거를 동정적으로 미화하지 않는다. 결말은 용서가 아니라 인정과 책임이다.
- 잔혹 묘사 없음. 화재·죽음은 암시로만 표현한다.

## 3. 사건의 진실 (플레이어에게 점진적으로 공개)

1. 1학년 때 재민과 가해자 3명이 도윤을 지속적으로 괴롭힘. 담임은 알면서 방관.
2. 사건 당일, 과학실에서 괴롭힘 도중 약품 화재 발생.
3. 도윤은 과학실 **준비실**에 갇힘. 재민은 **갇힌 걸 알면서도 혼자 도망침**.
4. 도윤 사망. 학교는 단순 사고로 **덮음**.
5. 재민은 전학, 사건과 도윤에 관한 기억을 외면 → 해리성 기억상실.
6. 시골 학교라 학생 수 부족으로 이후 폐교.
7. 10년 후, 서진이 굿을 시작한 날부터 재민의 악몽이 시작됨. 재민의 우편함에 서진의 명함이 꽂혀 있었고, 재민은 그 무당을 찾아감 (우연이 아니라 서진의 설계).

- 오프닝 꿈에서 쫓던 "누군가" = 준비실 쪽으로 도망치던 도윤 (사건 직전 장면)
- 서진이 건넨 것: **지도 + 부적**. 부적은 보호용이 아니라 폐교의 결계를 여는 장치 (5장에서 문이 닫힐 때 부적이 희미하게 빛남 → 복선)
- 문이 닫힌 순간부터 휴대폰은 "서비스 없음". 서진의 전화만 걸려온다.

## 4. 게임 시스템

### 4.1 조작
| 키 | 기능 |
|---|---|
| WASD / 방향키 | 이동 |
| E / Space | 조사·대화·대사 넘기기 |
| ESC | 메뉴 (기억 노트, 설정) |

### 4.2 핵심 루프
탐색 → 단서 수집 → 퍼즐 → **기억 재구성(추리)** → 학교 변화 → 새 구역

### 4.3 기억 재구성 (추리)
- 기억 조각 획득 시 빈칸 문장이 제시되고, 단서 카드로 채운다.
- 선택지 중 일부는 **왜곡된 보기** (예: "나는 말리려 했다").
- 왜곡을 고르면 → 화면 일그러짐 연출 + **부정 수치 상승**. 증거 카드를 제시하면 왜곡이 깨지고 정답으로 진행.

### 4.4 부정 수치
- 왜곡 선택 시 상승.
- 높을수록 그림자 출현 빈도·환각 증가.
- 최대치 → 게임오버 ("학교에 붙잡힘").
- 엔딩 조건에 반영.

### 4.5 과거 겹쳐보기
- 기억 조각을 얻은 핵심 장소 4곳에서만 사용. 그날의 공간이 겹쳐 보임.
- 현재/과거 비교 퍼즐에 사용.

### 4.6 추격
- 2번째 퍼즐(경비실, 2층 열쇠 획득)을 푼 시점부터 등장.
- 추격 시작 직전 자동저장.
- 잡히면 즉시 게임오버 → 추격 직전 저장 지점에서 재시작 (푼 퍼즐 상태 유지).
- 사물함에 숨기 가능. 숨으면 **1인칭 시점**으로 전환 — 사물함 문 통풍구 틈으로 복도가 보이고, 그림자가 가까울수록 틈 너머 실루엣이 커지고 시야가 떨린다.

### 4.7 기타
- 힌트: 막혔을 때 주인공 독백으로 힌트
- 아이템 조합: 없음
- 기억 노트(ESC 메뉴): 단서 카드, 인물 관계, 타임라인 자동 정리
- 2회차 요소: 엔딩 목록, 기억 조각 수집률

## 5. 맵

학교 이름: **IT희망학교**

| 층 | 장소 |
|---|---|
| 1층 | 입구, 복도, 1학년 3반(주인공 반), 빈 교실 ×2 (분위기·숨기용), 경비실, 교무실, **과학실 + 준비실**, 화장실 |
| 2층 | 음악실, 컴퓨터실, 방송실, 화장실 |

- 1층의 교무실·과학실은 처음엔 잠겨 있다가 후반에 열림 (1층 재방문 동선).

## 6. 챕터 구성과 퍼즐 (총 8개)

| 챕터 | 장소 | 퍼즐 / 이벤트 | 결과 |
|---|---|---|---|
| 0. 프롤로그 | 꿈 → 침실 → 무당 → 폐교 앞 → 진입 | 컷신 + 침실 조작 튜토리얼 (우편함 명함 복선) | 지도·부적 획득, 문 닫힘, 휴대폰 서비스 없음 |
| 1. 첫 교실 | 1-3반 교실 | 이벤트: **출석부** — 빨간 줄로 지운 이름, 옆 칸에 재민 이름. 마지막 출석일 = 사건 날짜 | 사건 날짜 단서 |
| | 1-3반 교실 | **P1 좌석 추리**: 학급 사진 뒷번호 + 출석부 + 책상 낙서 → 지워진 이름의 자리 | 낙서 공책 → **조각 1** + 추리 1 |
| | 경비실 | **P2 열쇠함**: 순찰 일지의 사건 날짜 기록 → 번호 | **2층 열쇠**, 학교 변화 1단계, 자동저장, 첫 추격 |
| 2. 2층 | 음악실 | **P3 피아노**: 도윤의 악보대로 연주 | 일기장 → **조각 2** |
| | 컴퓨터실 | **P4 PC 비밀번호 + 닉네임 매칭** | 단톡방 로그 → **조각 3** |
| | 방송실 | **P5 테이프 순서 맞추기** | 사건 당일 소리 단서, **옥상 열쇠** |
| | 2층 화장실 | 이벤트: **거울** — 재민의 과거 모습, "너는 기억하고 있어" | **조각 4** |
| 3. 옥상 | 옥상 | **P6 기억 재구성**: 실루엣 배치·대사 맞추기, 첫 본격 왜곡 선택지 | **조각 5**, 교무실 열쇠. "……내가 한 건가?" |
| 4. 교무실 | 1층 교무실 | **P7 서류함 + 먹칠된 이름 대조** (담임 서랍 속 원본) | 상담 기록, 친구 시절 사진 → **조각 6**, 과학실 열쇠 |
| 5. 과학실 | 1층 과학실·준비실 | **P8 타임라인 + 준비실 문 흔적** (과거 겹쳐보기) | 최종 추리 → "……내가 했어." → **조각 7**, 도윤 귀신 등장 |
| 6. 최종 | 준비실 → 출구 | 도윤의 가방(유품) 속 누나와 찍은 사진 → 서진의 정체, 서진의 전화 → 행동 선택 | 엔딩 분기 |

- **조각 8 (숨겨진 조각)**: 2층 거울 이벤트를 본 뒤 **1층 화장실 거울**을 다시 조사하면 획득
- 학교 변화 단계: 초반(낡고 조용함) → 중반(낙서·환청, 2층 열쇠 이후) → 후반(사고 당일과 현실이 겹침, 옥상 이후)
- 서진의 전화 대사에 추가: "네가 날 찾아온 게 우연이라고 생각했니?"

## 7. 엔딩

최종 선택은 행동으로 한다: 출구로 유품·증거를 들고 나감 / 과학실에서 태움 / 버리고 나감.

| 조건 | 엔딩 |
|---|---|
| 과학실에서 증거를 태움 | **엔딩 1 — 불꽃 속의 교실**: 불이 번져 갇힘 (그날의 반복). 불길 너머 도윤이 바라봄 |
| 증거를 버리고 탈출 / 조각 부족 / 부정 수치 높음 | **엔딩 2 — 끝나지 않는 괴롭힘**: 학교에서는 인정했지만 세상에는 숨긴 결말. 일상에서도 "왜 기억하지 못해?" |
| 조각 8개 + 부정 수치 낮음 + 증거·유품을 들고 탈출 | **엔딩 3 — 고백**: 증거 전달(학교의 은폐 포함). 서진과 마주함 — 서진은 **무표정으로 바라봄**. 도윤이 잠시 나타났다 사라짐 |
| 부정 수치 최대 (추격 중) | **게임오버 — 붙잡힘** |

- 조각이 부족하면 최종 증거 일부가 아예 나타나지 않음 (조건 공백 방지)

## 10. 구현 현황

- 2026-10-10: 프롤로그(꿈 → 침실 → 무당 → 폐교 앞 → 진입) + 1장(P1 좌석 추리, 조각 1, 추리 1, P2 열쇠함, 첫 추격) 플레이 가능. 계단을 오르면 대사 후 2층 복도 스텁(음악실·컴퓨터실·방송실·화장실 문 잠김, 2장 콘텐츠는 추후)을 거쳐 데모 종료
- 1·2·3반 책상은 모두 4열×4행(16개)으로 통일. 3반 자리 배치도 퍼즐(P1)은 분단별 번호 범위를 화면에 표시해 난이도를 낮춤
- 그래픽·사운드는 임시(코드 생성). CG 자리에는 "[CG] 설명" 텍스트 표시
