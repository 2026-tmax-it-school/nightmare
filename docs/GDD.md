## 1. 주제와 핵심 컨셉

- 주인공은 기억을 **잃은 것**이 아니라, 자신의 죄를 외면해 **기억하지 못하게 된 것**이다.
- 플레이어는 단서를 모아 **기억을 추리로 재구성**한다. 이 과정에서 주인공의 마음이 만든 **왜곡된 선택지**가 섞여 나오고, 그것을 고르는 행위 자체가 "외면"이 된다.
- 주인공의 과거를 동정적으로 미화하지 않는다. 결말은 용서가 아니라 인정과 책임이다.
- 잔혹 묘사 없음. 화재·죽음은 암시로만 표현한다.

## 3. 사건의 진실 (플레이어에게 점진적으로 공개)

1. 1학년 때 재민과 가해자 3명이 도윤을 지속적으로 괴롭힘. 담임은 알면서 방관.
2. 사건 당일, 과학실에서 괴롭힘 도중 약품 화재 발생.
3. 도윤은 과학실 **준비실**에 갇힘. 재민은 **갇힌 걸 알면서도 혼자 도망침**.
4. 도윤 사망. 학교는 단순 사고로 **덮음**.
5. 재민은 전학, 사건과 도윤에 관한 기억을 외면 → 해리성 기억상실.
6. 시골 학교라 학생 수 부족으로 이후 폐교.
7. 10년 후, 서진이 굿을 시작한 날부터 재민의 악몽이 시작됨. 재민의 우편함에 서진의 명함이 꽂혀 있었고, 재민은 그 무당을 찾아감 (우연이 아니라 서진의 설계).

- 오프닝 꿈에서 쫓던 "누군가" = 준비실 쪽으로 도망치던 도윤 (사건 직전 장면)
- 서진이 건넨 것: **지도 + 부적**. 부적은 보호용이 아니라 폐교의 결계를 여는 장치 (5장에서 문이 닫힐 때 부적이 희미하게 빛남 → 복선)
- 문이 닫힌 순간부터 휴대폰은 "서비스 없음". 서진의 전화만 걸려온다.

## 4. 게임 시스템

### 4.1 조작
| 키 | 기능 |
|---|---|
| WASD / 방향키 | 이동 |
| E / Space | 조사·대화·대사 넘기기 |
| ESC | 메뉴 (기억 노트, 설정) |

### 4.2 핵심 루프
탐색 → 단서 수집 → 퍼즐 → **기억 재구성(추리)** → 학교 변화 → 새 구역

### 4.3 기억 재구성 (추리)
- 기억 조각 획득 시 빈칸 문장이 제시되고, 단서 카드로 채운다.
- 선택지 중 일부는 **왜곡된 보기** (예: "나는 말리려 했다").
- 왜곡을 고르면 → 화면 일그러짐 연출 + **부정 수치 상승**. 증거 카드를 제시하면 왜곡이 깨지고 정답으로 진행.

### 4.4 부정 수치
- 왜곡 선택 시 상승.
- 높을수록 그림자 출현 빈도·환각 증가.
  - 30 이상: 탐색 중 가끔 가짜 발소리 + 짧은 화면 일그러짐 (환각)
  - 60 이상: 위 환각에 더해 어둠 속에 그림자가 잠깐 서 있다가 사라짐 (쫓아오지 않음)
- 최대치(100) → 게임오버 ("학교에 붙잡힘"). 추격 중이 아니어도 탐색으로 돌아오는 즉시 붙잡힌다.
- 왜곡 선택 1회 = +15.
- 엔딩 조건에 반영.

### 4.4-2 죄책감 (잔류 죄책감, 2026-10-17, 이슈 #78)
- 잊힌 기억을 되찾을수록 진실에 다가가고, 그만큼 내면이 무너진다. 부정 수치(진실을 **외면**한 정도)와 따로 두는 **진실에 다가간** 정도 — 진실을 마주해도, 외면해도 괴로운 구조
- 단계는 되찾은 기억 조각 수로 정한다 (따로 저장·UI 게이지 없음): 0~2개 = 1단계, 3~5개 = 2단계, 6~8개 = 3단계
- 공포 연출만 하고 게임오버·엔딩 판정에는 쓰지 않는다. 탐색 중에만 일어난다: 대화·이벤트·퍼즐·추격·사물함·기억 노트가 시작되면 진행 중인 연출(떠오른 글자·화면 기울기·키 반전)을 바로 거두고, 끝난 뒤 10초는 쉰다. 부정 수치 환각 직후 8초도 겹치지 않게 쉰다
  - 2단계: 35~55초마다 환청(속삭임 / 닫힌 문 긁는 소리 / 귀에 붙어 웅얼거리는 목소리) + 화면에 잠깐 떠오르는 목소리(도윤·가해자들) + 짧은 일그러짐
  - 3단계: 환청 18~30초마다, 그때 화면이 살짝 기울고 출렁인다(시야 왜곡). 45~75초마다 심장 소리·흔들림으로 예고한 뒤 2.5초 동안 좌우 또는 상하 이동이 반전된다 (추격 중엔 반전하지 않음)
- 기억의 변질 (텍스트 반전): 같은 물건도 단계에 따라 묘사가 바뀌고, 3단계에선 과거의 죄가 드러나 의미가 뒤집힌다. 맵 스크립트 조건 `guiltAtLeast`. 대상: 1층 교실 책상·13번 책상·1-2반 칠판·화장실 칸막이·과학실 알코올램프·복도 쓰레기통, 2층 보면대·화장실 칸막이 (예: "낡은 책상. 서랍은 비어 있다." → "……어느 책상을 봐도, 그 애 책상에 칼로 긋던 소리가 들린다.")
- 묘사가 바뀐 물건은 반짝임(조사 결과가 달라지면 다시 반짝임)으로 다시 눈에 띈다

### 4.5 과거 겹쳐보기
- 기억 조각을 얻은 핵심 장소 4곳에서만 사용. 그날의 공간이 겹쳐 보임.
- 장소 (2026-10-10 확정): **1학년 3반, 옥상, 교무실, 과학실 준비실**. 시스템 구현은 5장 작업에서 한다.
- 현재/과거 비교 퍼즐에 사용.
- (2026-10-14 확정) 5장에서 과학실에 들어서면 **부적이 뜨거워지며** 능력이 열린다 (부적 복선의 1차 회수). 지정 장소에 서서 **Q** 키를 누르면 화면이 바랜 색으로 바뀌고 그날의 실루엣·물건이 겹쳐 보이며 대사가 흐른다. 장소마다 처음 볼 때 플래그가 남는다.
- 준비실 문 앞의 겹쳐보기는 필수(P8의 단서), 1-3반·옥상·교무실은 되돌아가 볼 수 있는 선택 요소.

### 4.6 추격
- 2번째 퍼즐(경비실, 2층 열쇠 획득)을 푼 시점부터 등장.
- 추격 시작 직전 자동저장.
- 잡히면 즉시 게임오버 → 추격 직전 저장 지점에서 재시작 (푼 퍼즐 상태 유지).
- 사물함에 숨기 가능. 숨으면 **1인칭 시점**으로 전환 — 사물함 문 통풍구 틈으로 복도가 보이고, 그림자가 가까울수록 틈 너머 실루엣이 커지고 시야가 떨린다. 틈 너머 풍경은 사물함이 놓인 장소에 따라 다르다 (복도 / 교실: 칠판·달빛 창문·책상 / 경비실: CCTV 모니터·열쇠함·철문 / 음악실: 깨진 창·피아노·보면대 / 방송실: ON AIR 등·콘솔·테이프 선반). 맵 데이터 사물함 오브젝트의 `view`로 지정.
- 추격은 총 3회: 1층(P2 직후), 2층(P4 단톡방을 본 직후), 1층 재방문(조각 6을 얻고 교무실을 나설 때). 추격 중에는 계단으로 층을 옮길 수 없다.
- 사물함 배치 (2026-10-17, 이슈 #63): 숨을 곳이 너무 많으면 긴장감이 떨어지므로 총 7개 — 1층 5개(1학년 1반·2반·교무실 각 1, 복도 x10·x20), 2층 2개(음악실, 복도 x11). 방당 1개 이하이고, 그림자가 나타나는 쪽(1층·2층 복도 오른쪽 끝)과 추격이 시작되는 방(경비실·컴퓨터실) 바로 앞에는 두지 않는다. 추격 중 잠긴 방송실에도 두지 않는다.
- 그림자 속도: 1·2번째 추격은 0.25초/칸, 3번째부터는 0.2초/칸 (플레이어 0.15초/칸보다는 느리다).
- 그림자 소리 (2026-10-17, 이슈 #62): 한 칸 움직일 때마다 끌리는 **발소리**, 따로 거친 **숨소리**. 플레이어와의 거리(칸)가 가까울수록 둘 다 커지고 숨소리 간격이 짧아지며, 12칸보다 멀면 들리지 않는다. 사물함에 숨어 있어도 근처를 서성이는 그림자의 소리가 들린다 (조금 먹먹하게). 따돌리거나 잡히거나 장면이 바뀌면 바로 멈춘다. 심장 박동·저음 드론 배경음은 그대로.

### 4.7 기타
- 힌트: 막혔을 때 주인공 독백으로 힌트
- 목표 패널 (2026-10-17, 이슈 #38): 탐색 화면 오른쪽 위에 항상 표시. 첫 줄은 장 이름과 그 장의 진행도(■□ 칸 + 완료/전체), 둘째 줄은 「지금 할 일」(힌트 문구). 장별 단계는 `data/objectives.json`. 기억 노트 「생각하기」 탭에도 같은 단계를 체크리스트로 보여 준다
- 진행 순서 (2026-10-17, 이슈 #38 → #57에서 축소): 방은 기본으로 열려 있어 언제든 둘러볼 수 있다. 막는 것은 두 가지뿐이고, 막힐 때 독백은 목적지를 아는 말투가 아니라 기억이 떠오르지 않는 말투로 한다 (예: "……뭔가 있을 것 같은데, 아직 떠오르지 않는다.")
  - 스토리를 건너뛰는 층 이동: 맵의 `gates` (추격 중엔 알림만). 2층 → 옥상 계단 ← P5·조각 4 (#41) / 옥상 → 내려가는 계단 ← 교무실 열쇠
  - 선행 목표 없는 퍼즐·이벤트: 방 문턱이 아니라 그 물건을 조사할 때 막는다. 경비실 열쇠함(P2) ← 조각 1·순찰 일지 / 컴퓨터실 PC(P4) ← 일기장 / 2층 거울(조각 4) ← P5 / 1층 거울(조각 8) ← 조각 4 / 12번 책상 ← P1 / 옥상 난간(P6) ← 옥상 단서 4개
  - 잠긴 문(2층 계단실·방송실·교무실·과학실 등)은 기존대로 열쇠·이벤트로 막는다
- 반짝임 (2026-10-17, 이슈 #52): 아직 조사하지 않은 물건에 조사 표시와 같은 모서리 테두리가 반짝인다. 손전등 시야 안, 지금 보이는 칸(레이캐스팅 시야)의 것만 보인다. 같은 방의 같은 종류(책상 16개 등)는 하나로 묶어 한 곳에만 띄우고, 하나를 조사하면 함께 꺼진다. 조사 결과가 달라지면(예: 전화 후 알코올램프·쓰레기통, 열쇠를 얻은 뒤의 잠긴 문) 다시 반짝인다. 사물함(숨기)은 제외. 그림 없는 조사 지점(옥상 새김 글씨, 음악실 창문)도 같은 방식으로 보인다

### 6.2 3장 옥상 상세 (2026-10-10 확정, 이슈 #20)

옥상의 기억은 **7월 13일 방과후** — 가해자 셋과 재민이 "내일 피아노 왕자를 과학실로 부르자"고 계획한 자리다 (일기장 「내일 방과후에 과학실로 오래. 재민이도 온대.」의 전날).

진행: 옥상 도착 → 단서 4개 조사 → 난간의 낙서 「7.13」에서 **P6** → 조각 5 → 소화기함의 교무실 열쇠 → 학교 변화 2단계 + 1층 귀환. 옥상↔2층은 계단탑 계단으로 오갈 수 있다. 계단탑 철문 앞 양옆에 명찰(「문 앞」)과 소화기함(「출입문 옆」).
- (2026-10-17, 이슈 #37) P6 지점은 위쪽 난간 한 칸에 녹슨 자리와 긁힌 「7.13」이 그려져 있어 멀리서도 다른 난간과 구분된다. 목표 패널도 「위쪽 난간의 「7.13」 낙서」로 위치를 알려 준다.

| 단계 | 내용 |
|---|---|
| 단서 | 물탱크 옆 담배꽁초(사이에 「1번」 출석 카드) / 펜스 앞 축구공(매직 「7」) / 벤치 위 만화책(「10번 거」) / 문 앞 떨어진 명찰(「윤재민」) |
| **P6-1 실루엣 배치** | 옥상 약도의 자리 4곳(물탱크 옆·펜스 앞·벤치·문 앞)에 「일등」·「럭키7」·「텐」·재민을 배치 |
| **P6-2 대사 맞추기** | 인물마다 그날의 대사를 고른다. 일등 「내일 방과후 과학실 ㄱ. 피아노왕자 불러.」 / 럭키7 「쌤 오면 내가 망볼게.」 / 텐 「과학실 약품 좀 갖고 놀아 볼까 ㅋ」 / 재민 「내가 데려올게. 걔 내 말은 들어.」 |
| 왜곡 선택 | 재민의 보기에 「……그만하자. 걔 불쌍하잖아.」 「난 빠질게.」가 섞인다. 고르면 왜곡(+15) → 증거 「7월 13일. 내일 방과후에 과학실로 오래. 재민이도 온대.」(도윤의 일기장)로 깨진다 |
| 보상 | **조각 5 「내가 데려올게」**, "……내가 한 건가?", 옥상 출입문 옆 소화기함의 **교무실 열쇠**(담임이 숨겨 둔 것 — 은폐 복선) |
| 학교 변화 2단계 | 교무실 열쇠를 얻으면 `stage2`: 붉은 기운이 짙어지고 1·2층 바닥에 그을음 자국과 새 낙서. 자동으로 1층 계단실로 내려가며 귀환 연출 |

- 교무실 열쇠로 1층 교무실 문을 열면 4장이 시작된다 (6.3).
- 학교 변화 단계: 초반(낡고 조용함) → 중반(낙서·환청, 2층 열쇠 이후) → 후반(사고 당일과 현실이 겹침, 옥상 이후)
- 서진의 전화 대사에 추가: "네가 날 찾아온 게 우연이라고 생각했니?"

### 6.3 4장 교무실 상세 (2026-10-14 확정, 이슈 #21)

교무실의 진실은 **학교와 담임의 은폐**다. 도윤은 사건 전에 두 번 담임을 찾아가 도움을 청했지만 담임은 아무것도 하지 않았고, 학교는 사고 경위서에서 그 사실을 먹칠로 지웠다.

진행: 교무실 문 열기(4장 배너·자동저장) → 서류함의 먹칠된 사고 경위서 → 담임 책상의 액자 사진과 서랍 쪽지 → 서랍 번호 자물쇠 → 상담 기록 원본 → **P7** → 조각 6·과학실 열쇠 → 교무실을 나서면 3번째 추격 → 과학실 열쇠로 과학실 문을 열면 5장 (6.4).

| 단계 | 내용 |
|---|---|
| 서류함 | 「학생 사고 처리 — 대외비」 파일의 **사고 경위서**. 「원인 — 학생 개인의 실험 부주의」. 아래 몇 줄은 검은 매직으로 먹칠 |
| 액자 사진 | 담임 책상 위에 엎어진 액자. 중학교 교복을 입은 재민과 도윤이 피아노 앞에서 웃는 사진. 뒷면 「7월 5일. 도윤이가 첫 상담 때 두고 간 사진. "우리 원래 친구였어요."」 |
| 서랍 자물쇠 | 담임 책상 맨 아래 서랍. 쪽지 「그 아이가 처음 찾아온 날.」 → keypad `0705` |
| 상담 기록 원본 | 7월 5일: 도윤이 1·7·10번의 괴롭힘을 호소, 13번 윤재민도 함께 있다고 함. 조치 — 학부모 통보 보류, 학기말까지 지켜봄. 7월 13일: 「선생님, 내일 방과후에 과학실로 오래요.」 「알았다, 내가 가 보마.」 ── 가지 않았다 |
| **P7 대조** | 상담 기록 원본을 보며 경위서의 먹칠된 칸 4개를 채운다: 현장 인원(도윤과 학생 4명) / 사전 징후(괴롭힘 상담 2회) / 담임 조치(학부모 통보 보류) / 현장에 있던 학생(1번·7번·10번·**13번 윤재민**) |
| 왜곡 선택 | 마지막 칸에 「없음 ── 재민은 그날 먼저 귀가했다」가 섞인다. 고르면 왜곡(+15) → 증거 「7월 5일 상담 — 윤재민(13번)도 함께 있다고 함」으로 깨진다 |
| 보상 | 기억 재생(교무실 앞 복도에서 상담을 마친 도윤에게 「너 쌤한테 꼰질렀냐?」) → **조각 6 「고자질」**. 기록철 맨 뒤의 **과학실 열쇠**(꼬리표 「과학실 — 사고 후 봉인」) |
| 1층 추격 | 조각 6을 얻고 교무실 문 앞 복도로 나서면 시작. 그림자는 과학실 앞 복도에서 나타나 0.2초/칸으로 쫓아온다. 복도 사물함은 그림자 쪽에 있으므로 교무실 안 구석에 사물함을 하나 둔다 (되돌아가 숨기). 추격 직전 자동저장 |

### 6.4 5장 과학실 상세 (2026-10-14 확정, 이슈 #21)

**그날의 진실 (확정)**: 텐의 약품 장난으로 병이 깨지고 불이 붙자 도윤은 준비실로 피했고, 망을 보던 럭키7이 장난 삼아 **바깥 걸쇠**를 걸었다. 경보가 울리자 셋은 도망쳤고 문 앞엔 재민만 남았다. 도윤이 문을 두드리며 재민의 이름을 불렀고, 재민은 **걸쇠를 풀 수 있었지만 풀지 않고 달아났다**. 「……내가 했어.」는 이 선택을 인정하는 말이다.

맵: 1층 과학실 구역(x23~33)을 벽으로 나눠 **과학실**(x23~29)과 **준비실**(x31~33)로 만든다. 준비실 문은 (30,16).

진행: 과학실 문 열기(5장 배너·자동저장) → 과학실에 들어서면 부적이 뜨거워지며 **과거 겹쳐보기(Q)** 해금 → 과학실 단서(약품장·깨진 약품병·안전 수칙) → 준비실 문 흔적 → 문 앞에서 겹쳐보기 → **P8** → 최종 추리 → 「……내가 했어.」 → 조각 7 → 재민이 걸쇠를 풀고 준비실 문이 열림 → 도윤 귀신.

| 단계 | 내용 |
|---|---|
| 과학실 단서 | 약품장 「7월 14일 이후 기록 없음. 알코올 1병 분실」 / 실험대의 깨진 약품병 / 벽의 안전 수칙 「준비실 문은 안에서 열리지 않음. 바깥 걸쇠 사용 후 반드시 확인할 것」 |
| 준비실 문 흔적 | 바깥쪽에 녹슨 걸쇠가 걸린 채로 굳어 있고, 문 안쪽 아래에 손톱으로 긁은 자국. 부적이 뜨거워진다 → 여기서 겹쳐보기 |
| 문 앞 겹쳐보기 (필수) | 럭키7이 문을 닫고 걸쇠를 건다 → 경보, 발소리가 흩어진다 → 문 앞에 남은 재민 → 「재민아… 열어 줘.」 → 걸쇠에 닿았다가 떨어지는 손 |
| **P8 타임라인** | 사건 카드 6장을 시간 순서로 놓는다: 재민이 도윤을 데리고 들어온다 → 「너도 웃기지?」「……응.」 → 텐의 약품 장난, 병이 깨지고 불 → 도윤이 준비실로 피하고 걸쇠가 걸린다 → 경보, 셋은 도망치고 재민만 남는다 → 문 두드리는 소리, 재민은 달아난다 |
| P8 왜곡 카드 | 「재민이 선생님을 부르러 뛰어간다」가 섞여 있다. 넣으면 왜곡(+15) → 증거 「준비실 문 흔적」(걸쇠는 한 번도 풀린 적 없이 녹슬어 있다)으로 깨지고 카드가 사라진다 |
| 최종 추리 | 빈칸 4개: 도윤을 데려간 건 「나」 / 걸쇠를 건 건 「럭키7」 / 문 앞에 남은 건 「나」(왜곡 「아무도 없었다」) / 나는 걸쇠를 「풀지 않고 달아났다」(왜곡 「풀었다」) → 「……내가 했어.」 |
| 보상 | 기억 재생(문 두드리는 소리와 재민을 부르는 목소리) → **조각 7 「걸쇠」**. 재민이 십 년 만에 걸쇠를 푼다 → 준비실 문이 열리고, 안쪽에 **도윤 귀신**이 잠시 서서 가방을 바라보다 사라진다 (공격하지 않음) |

- 선택 겹쳐보기: 1-3반(7월 14일 종례 직전, 재민이 도윤에게 「과학실 좀 가자」), 옥상(7월 13일, 「내가 데려올게」는 아무도 시키지 않은 말), 교무실(7월 13일, 담임이 상담 기록을 서랍 깊숙이 밀어 넣는다).

### 6.5 6장 최종 상세 (2026-10-14 확정, 이슈 #21)

진행: 준비실의 도윤의 가방(유품) → 6장 배너 → 가방 속 완성된 악보 「약속」과 **누나와 찍은 사진**(뒷면 「서진 누나랑」) → 재민이 무당의 얼굴을 알아본다 → **서진의 전화** → 최종 행동 선택 → 엔딩.

| 단계 | 내용 |
|---|---|
| 유품 | 도윤의 가방을 얻는다. 악보 「약속」 마지막 장에 「재민이 생일 선물 — 완성」 |
| 서진의 전화 | 「서비스 없음」인데 전화가 온다. 「네가 날 찾아온 게 우연이라고 생각했니?」 「부적은 너를 지키려던 게 아니야. 이 학교의 문을 닫고, 네 눈을 연 거지.」 → 부적이 마지막으로 빛나고 재가 되어 부서진다 (복선 회수). 「벌하러 부른 게 아니야. 말할 기회를 주려고 부른 거지.」 「들고 나오든, 버리든…… 그날처럼 태우든.」 「현관문은 열어 둘게.」 |
| 행동 선택 오브젝트 | 과학실 실험대의 **알코올램프**(불씨) → 가방을 태운다 / 복도의 **쓰레기통** → 가방을 버린다 / 1층 **현관** → 들고 나간다 |
| 탈출 추격 | 없음 (2026-10-14 결정. 9장 참고) |

### 6.6 엔딩 판정 (2026-10-14 확정)

- 알코올램프에서 태우면 즉시 **엔딩 1**.
- 현관으로 나갈 때: 가방을 버렸거나 들고 있지 않음 → **엔딩 2**. 가방을 들었지만 **조각 8개 미만**이면 가방 속 「증거」 USB가 사라져 있음 → **엔딩 2**. 부정 수치 **30 이상**이면 「……정말, 말할 수 있을까.」 → **엔딩 2**. 조각 8개 + 부정 수치 30 미만 + 가방 → 「증거」 USB → **엔딩 3**.

| 부정 수치 최대 (추격 중) | **게임오버 — 붙잡힘** |

- 조각이 부족하면 최종 증거 일부가 아예 나타나지 않음 (조건 공백 방지) — 조각 8개 미만이면 가방 속 「증거」 USB가 없다 (6.6)
