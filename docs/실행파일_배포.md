# 단일 실행 파일 배포

`dist/ForgottenClassroom-Windows.exe`는 Windows x64용,
`dist/ForgottenClassroom-Mac`은 Mac Apple Silicon(M1 이상)용입니다.
각 운영체제에 맞는 파일 하나만 전달하면 됩니다. Python·Go·별도 게임 폴더는 필요하지 않습니다.

## 플레이

1. 실행 파일을 더블클릭합니다.
2. 기본 웹 브라우저가 열리고 게임 타이틀이 나타납니다. 타이틀에서 시작하면 소리가 재생됩니다.
3. 게임을 하는 동안 실행 파일의 터미널 창을 열어 둡니다.
4. 종료하려면 터미널 창을 닫거나 Ctrl+C를 누릅니다. 브라우저 탭만 닫으면 서버는 계속 실행됩니다.

게임·Phaser 3.80.1·폰트를 실행 파일에 포함하므로 플레이할 때 인터넷이 필요하지 않습니다.
브라우저 자동 실행이 실패하면 `http://127.0.0.1:18123/`을 직접 엽니다.
개발자 화면은 일반 화면에서 **P**로 열 수 있습니다.

저장과 엔딩 기록은 브라우저의 localStorage에 남습니다. 실행 파일 안에 저장되지 않으며,
같은 브라우저·프로필을 써야 이어할 수 있습니다. 기존 개발 서버(`localhost:8123`)나
온라인 배포 주소의 저장과는 별개입니다. 시크릿 창이나 브라우저 데이터 삭제는 저장 유지에 적합하지 않습니다.

고정 포트 18123을 사용합니다. 같은 버전을 다시 실행하면 기존 서버의 게임을 엽니다.
다른 버전이나 다른 프로그램이 포트를 쓰고 있다면 해당 프로그램을 종료한 뒤 다시 실행합니다.
업데이트는 이전 서버를 종료하고 새 실행 파일을 실행하면 됩니다.

현재 산출물은 배포 인증서로 서명·공증하지 않았습니다. 외부로 전달받은 파일은
운영체제의 실행 확인이 표시되거나 조직의 보안 정책에 따라 차단될 수 있습니다.
Mac Intel용 파일은 포함하지 않습니다.

## 다시 빌드하기

빌드하는 컴퓨터에 Python 3.10 이상과 [Go 1.22 이상](https://go.dev/doc/install)이 필요합니다.
게임 파일을 실행 파일에 넣는 데 [Go embed](https://pkg.go.dev/embed)를 사용합니다.

```sh
python3 tools/build_release.py --target all
# 한 플랫폼만: --target windows 또는 --target macos
# Go가 PATH에 없다면:
GO=/path/to/go python3 tools/build_release.py --target all
```

첫 빌드에는 엔진·폰트·라이선스를 다운로드할 인터넷 연결이 필요합니다.
다운로드는 `.build/downloads/`에 캐시하고, 임시 빌드 파일은 `.build/launcher/`에 둡니다.
`.build/`와 `dist/`는 Git에 포함하지 않습니다. 콘텐츠나 코드 수정 후에는 다시 빌드해야 합니다.
엔진과 폰트의 라이선스는 실행 파일의 `vendor/licenses/`에 내장합니다.

서버만 검사할 때는 실행 파일에 `--no-browser`를 붙이면 브라우저를 열지 않습니다.
