# 「잊힌 교실」 4분 시연 대본

핵심 메시지: **"기억을 잃은 게 아니라, 외면해서 기억하지 못하게 된 주인공이 단서로 기억을 다시 맞춘다."**
흐름: 분위기 → 퍼즐 → 추격 → **기억 재구성(왜곡)** → 과거 겹쳐보기

## 발표 전 준비 (필수)

1. 저장소 루트에서 서버 실행: `python tools/serve.py` → 브라우저에서 `http://localhost:8123`
2. **처음 불러오기가 약 10초** 걸린다. 발표 직전에 아래 6개 주소를 탭으로 미리 열어 「아무 키나 눌러 시작」 화면까지 띄워 둔다.
   - ① `http://localhost:8123/` (타이틀)
   - ② `http://localhost:8123/?dev&start=school` (1층 진입)
   - ③ `http://localhost:8123/?dev&start=p3` (음악실 피아노)
   - ④ `http://localhost:8123/?dev&start=chase2` (2층 추격)
   - ⑤ `http://localhost:8123/?dev&start=p6` (옥상 기억 재구성)
   - ⑥ `http://localhost:8123/?dev&start=lab` (과학실 겹쳐보기)
3. 탭마다 화면을 **한 번 클릭**해 둔다 (브라우저 소리 정책 때문에 클릭 전엔 소리가 안 남).
4. 소리를 크게. 기억 노트(ESC) → 설정 탭에서 전체 볼륨 확인.
5. 개발자 모드는 탭마다 저장 칸이 따로라 본 게임 저장에 영향 없음. 꼬이면 그 탭을 새로고침.

## 단계별 조작과 멘트

### ① 타이틀 (0:00–0:20)
- 조작: 아무 키 → 타이틀 「잊힌 교실」
- 멘트: "탑뷰 공포 추리 게임 「잊힌 교실」입니다. 학교폭력과 죽음을 다루고, 잔혹 묘사 없이 암시로만 표현합니다."

### ② 1층 진입 (0:20–0:55)
- 조작: Space로 시작 → 대사 넘기기(Space) → **↑**로 복도까지 → **→**로 복도를 따라 이동(사물함 피해서 한 줄 아래로) → 1학년 3반 문 앞(x25)에서 **↑**
- 보여줄 것
  - 손전등이 닿는 곳만 밝고, 벽에 가려진 곳은 안 보임(레이캐스팅 시야). **열린 문 너머가 부채꼴로만 보이는 장면**이 좋다
  - 아직 조사 안 한 물건 위의 **별빛 반짝임**, 물건 앞에 서면 물건 전체를 감싸는 괄호 + 윤곽 빛
  - 문을 지날 때 「드르륵」
- 멘트: "손전등과 시야 계산으로 보이는 곳만 보입니다. 반짝이는 별빛이 조사할 수 있는 물건입니다."

### ③ 음악실 P3 피아노 (0:55–1:35)
- 조작: Space로 시작 → 바로 앞 피아노 **Space** → 대사 넘기기 → 「쳐 본다」 → 숫자 **3 5 6 5 3 2 1 2** (미 솔 라 솔 미 레 도 레)
- 보여줄 것: 악보의 지워진 두 칸 「미 솔 ■ 솔 | 미 ■ 도 레」 + 칠판의 남은 계이름을 겹쳐 푸는 구조. 성공하면 「마지막 음이 어둠 속으로 번져 사라진다」 → 피아노 의자 뚜껑이 열림
- 멘트: "2층에 올라오면 음악실 쪽에서 「미, 솔」 두 음이 들리고, 가까울수록 커져서 소리로 길을 찾습니다. 악보와 칠판 단서를 겹쳐 곡을 완성합니다."

### ④ 2층 추격 + 숨 참기 (1:35–2:35)
- 조작: Space로 시작 → 「……발소리가 다가온다」 Space → **바로 앞 사물함에서 Space(숨기)** → 미니게임이 뜨면 **고리가 심장에 겹치는 순간 Space** (총 6박)
  - 박동은 시작 후 약 2.4 / 5.0 / 7.8 / 10.2 / 13.2 / 16.6초. **박 간격이 2~3초로 아주 느리다** — 서두르지 말 것
  - 엉뚱할 때 누르면 「헉」 → 소리 게이지가 오른다. 게이지가 차면 붙잡혀 게임오버(그것도 시연 거리가 됨)
- 보여줄 것: 사물함 통풍구 틈 1인칭 시점, 다가오는 그림자 실루엣, 「……킁」 냄새 맡기, 성공 시 「……발소리가 멀어졌다」
- 멘트: "추격은 세 번 나오고 숨을 때마다 반응이 다릅니다. 두 번째는 심장 박동에 맞춰 숨을 죽이는 리듬 게임입니다."

### ⑤ 옥상 P6 기억 재구성 (2:35–3:35) — 핵심
- 조작: Space로 시작 → 바로 앞 난간 「7.13」 **Space** → 대사 넘기기 → 「떠올린다」
  - **자리 놓기**: ↑↓로 사람을 고르고 **E**. 놓을 때마다 고르는 칸이 맨 위로 돌아간다 → 일등(E) / 럭키7(↓1번, E) / 텐(↓2번, E) / 재민(↓3번, E)
  - **대사 맞추기**: 일등(E) / 럭키7(↓1, E) / 텐(↓2, E)
  - **재민 차례에서 일부러 첫 번째 「……그만하자. 걔 불쌍하잖아.」를 E** → 붉게 일그러지고 「……기억이 일그러진다」 → **[증거] 도윤의 일기장**이 왜곡을 깨고 「내가 데려올게. 걔 내 말은 들어.」로 바뀜 → E → 그날의 기억이 한 줄씩
- 멘트: "이 게임의 핵심입니다. 주인공은 기억을 잃은 게 아니라 외면한 겁니다. 그래서 선택지에 주인공이 **믿고 싶은 왜곡된 기억**이 섞여 있고, 그걸 고르면 부정 수치가 오르고 증거가 그 기억을 깨뜨립니다. 부정 수치가 높으면 그림자와 환각이 늘고, 엔딩도 바뀝니다."

### ⑥ 과학실 과거 겹쳐보기 (3:35–3:55)
- 조작: Space로 시작 → 대사 넘기기 → **↓ 2칸, ← 1칸**(과학실 가운데) → **Q**
- 보여줄 것: 화면이 바랜 색으로 바뀌고 그날 방과후의 실루엣(텐·일등 등)과 물건이 겹쳐 보임 → 「야, 이거 불 위에 부으면 색 바뀐대 ㅋㅋ」. 지금과 그날의 차이를 찾는 퍼즐로 이어짐
- 멘트: "후반에는 부적의 힘으로 그날의 공간을 겹쳐 보고, 지금과 다른 곳을 찾아 진실에 다가갑니다."

### 마무리 (3:55–4:00)
- 멘트: "마지막엔 도윤의 유품을 들고 나갈지, 태울지, 버릴지 **행동으로** 고르고, 모은 기억 조각과 부정 수치에 따라 엔딩 세 가지로 갈립니다."
