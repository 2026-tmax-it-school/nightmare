# 「잊힌 교실」 4분 시연 대본

핵심 메시지: **"기억을 잃은 게 아니라, 외면해서 기억하지 못하게 된 주인공이 단서로 기억을 다시 맞춘다."**
흐름: **기억 재구성(왜곡)** → 추격 → 진실 「내가 했어」 → 마지막 선택. 프롤로그는 PPT로 설명하고 시연은 장면 4개만 보여 준다.

## 발표 전 준비 (필수)

1. 저장소 루트에서 서버 실행: `python tools/serve.py` → 브라우저에서 `http://localhost:8123`
2. **처음 불러오기가 약 10초** 걸린다. 발표 직전에 아래 4개 주소를 탭으로 미리 열어 「아무 키나 눌러 시작」 화면까지 띄워 둔다.
   - ① `http://localhost:8123/?dev&start=frag1` (12번 책상 → 기억 재구성)
   - ② `http://localhost:8123/?dev&start=p2` (경비실 열쇠함 → 첫 추격)
   - ③ `http://localhost:8123/?dev&start=p8` (준비실 문 → 최종 추리)
   - ④ `http://localhost:8123/?dev&start=frag7` (도윤의 가방 → 서진의 전화)
   - (여유) ⑤ `http://localhost:8123/?dev&start=frag5` (옥상 소화기함 점프스케어)
3. 탭마다 화면을 **한 번 클릭**해 둔다 (브라우저 소리 정책 때문에 클릭 전엔 소리가 안 남).
4. 소리를 크게. 기억 노트(ESC) → 설정 탭에서 전체 볼륨 확인.
5. 개발자 모드는 저장 칸이 따로라 본 게임 저장에 영향 없음. 꼬이면 그 탭을 새로고침.
6. 대사는 E를 연타해 넘기고, 아래 **굵게** 적은 순간에만 멈춰 설명한다.

## 시간표 (총 4:00)

| 시간 | 탭 | 보여 줄 것 |
|---|---|---|
| 0:00–0:10 | — | 시작 멘트 (화면 없이) |
| 0:10–1:20 | ① 12번 책상 | **기억 재구성 + 왜곡 선택지 + 증거로 깨기** (핵심) |
| 1:20–2:20 | ② 경비실 | 열쇠함 → 학교 변화 → 그림자 추격 → 사물함 1인칭 |
| 2:20–3:20 | ③ 준비실 문 | 그날의 순서 → 최종 추리 「……내가 했어.」 → 도윤 귀신 |
| 3:20–3:50 | ④ 준비실 가방 | 누나 사진 「……한. 한서진.」 → 서진의 전화 |
| 3:50–4:00 | — | 마무리 멘트 |

## 단계별 조작과 멘트

### 시작 (0:00–0:10)
- 멘트: "주인공은 기억을 *잃은* 게 아니라, 자기 죄를 외면해서 *기억하지 못하는* 사람입니다. 플레이어는 폐교에서 단서를 모아 그 기억을 다시 맞춥니다."

### ① 기억 재구성 — 이 게임의 핵심 (0:10–1:20)
- 조작: 아무 키 → 바로 앞 12번 책상 **E** → 낙서 공책·기억 재생 대사 넘기기 → 추리 화면
  - 1줄 「출석번호 ＿번」: ↓1, E (12)
  - 2줄 「＿라고 불렀다」: ↓1, E (피아노 왕자)
  - 3줄 「나는 그 아이를 ＿」: **일부러 첫 번째 「모른다」를 E** → 붉게 일그러지고 **[증거] 낡은 공책 「재민이는 중학교 때 내 유일한 친구였는데.」**로 깨짐 → E → ↓1, E (알고 있었다)
- 멘트: "선택지 중에는 주인공이 진실을 피하려는 **왜곡된 보기**가 섞여 있습니다. 고르면 부정 수치가 오르고, 증거를 들이밀어야 깨집니다. 외면한 만큼 엔딩이 달라집니다."

### ② 추격 — 공포와 긴장 (1:20–2:20)
- 조작: 아무 키 → 바로 앞 열쇠함 **E** → 숫자 **0 7 1 4** → E → 웃음소리·「……발소리?」 대사 넘기기 → 추격 시작
  - 바로 **← 3칸, ↑ 3칸**(경비실 문을 나가 복도로) → **← 2칸** → **↑ 보고 E**(복도 사물함에 숨기)
  - 숨으면 사물함 통풍구 틈 1인칭 화면. 그림자가 다가왔다가 「……발소리가 멀어졌다」
  - 늦으면 붙잡혀 게임오버 → 「마지막 저장부터 다시」로 추격 직전부터 (그것도 시연 거리가 됨)
- 멘트: "그림자는 **"그날의 나"**입니다. 같은 줄에서 마주치면 숨을 들이켜고 돌진해 옵니다. 추격은 세 번이고, 첫 번째는 숨기만 하면 되지만 두 번째는 숨 참기, 세 번째는 문 붙잡기 미니게임이 붙어 갈수록 어려워집니다."

### ③ 진실 — "내가 했어" (2:20–3:20)
- 조작: 아무 키 → 바로 앞 준비실 문 **E** → 대사 넘기기 → **그날의 순서** 화면 (↑↓ 고르기, E 놓기. 고르는 칸은 제자리에 남는다)
  - 놓는 순서: 「재민이 도윤을 데리고 과학실에 들어온다」 → 「「너도 웃기지?」 「……응.」 웃음소리」 → 「텐의 약품 장난. 병이 깨지고 불이 붙는다」 → 「도윤이 준비실로 피하고, 바깥 걸쇠가 걸린다」 → 「경보. 셋은 도망치고, 문 앞엔 재민만 남는다」 → 「문 두드림. 걸쇠를 풀지 않고 달아난다」
  - 잘못 놓으면 Backspace로 하나 빼고 다시 놓는다
  - (시간이 있으면) 「재민이 선생님을 부르러 뛰어간다」를 놓아 왜곡 → 증거로 사라지는 것도 보여 줄 수 있다
- 최종 추리 (↑↓로 골라 E): 나였다 → 「럭키7」 → 나뿐이었다 → 풀지 않고 달아났다 → **「……내가 했어.」** → 준비실 문이 열리고 도윤 귀신
- 멘트: "마지막 기억은, 친구가 갇힌 걸 알면서 걸쇠를 풀지 않고 도망쳤다는 겁니다. 이 게임은 용서가 아니라 **인정**으로 끝납니다."

### ④ 마지막 선택 — 엔딩 분기 (3:20–3:50)
- 조작: 아무 키 → 바로 앞 가방 **E** → 누나 사진 **「……한. 한서진. 도윤이의 누나.」** → 서진의 전화까지
- 멘트: "주인공을 학교로 부른 무당은 피해자의 누나였습니다. 마지막엔 증거를 **태울지, 버릴지, 들고 나갈지** 직접 행동으로 고르고, 모은 기억과 외면한 횟수에 따라 엔딩 세 개로 갈립니다."

### 마무리 (3:50–4:00)
- 멘트: "기억 조각 8개, 퍼즐 8개, 엔딩 3개, 플레이 시간은 목표 약 20분입니다."

## 시간이 모자랄 때 뺄 순서
1. ③의 그날의 순서 화면 (최종 추리부터 보여 주려면 순서를 빨리 놓기만)
2. ④는 말로만 소개
3. ②는 열쇠함까지만 하고 추격은 말로 설명

## 시간이 남을 때
- ⑤ `frag5` 옥상 소화기함 **E** → 대사 넘기기 → 점프스케어 (물건을 처음 열 때 나오는 점프스케어가 4곳 있다)

## 리허설에서 확인한 것 (2026-10-24)

- ③·④는 이번 대본으로 아직 돌려 보지 않았다. 발표 전에 한 번 돌려 보며 시간을 잴 것
