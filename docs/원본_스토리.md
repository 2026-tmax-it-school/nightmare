# 원본 스토리 초안 (사용자 작성)

> 사용자가 처음 제공한 스토리보드 원문 요약. 현재 기준은 `docs/GDD.md`이며, 충돌 시 GDD가 우선한다.

## 장면 흐름
1. 오프닝 — 이상한 꿈: 어두운 화면, 소리만으로 진행 (달리는 발소리 → 흐느낌 → 뒤따르는 발소리 → 교실 문 닫힘 → 주인공을 부르는 목소리), 화면이 깨지며 전환
2. 침실: "또 그 꿈인가…" / "내가 왜 계속 학교 꿈을 꾸는 거지?" — 가해자였다는 사실은 숨김
3. 무당: "네가 잊어버린 게 있구나." / "네가 기억을 잃은 게 아니라… 네가 기억하지 못하게 된 거야." / 지도 획득 / "거기에 네 기억이 남아 있어."
4. 폐교 앞: 비 오는 밤, 낡은 학교 이름. "여기가… 내가 다니던 학교였나?" — 처음 보는 듯 익숙함
5. 진입: 끼이익— / "아무도 없는 것 같은데…" / 쾅. 뒤돌아보면 아무도 없음 → 조작 시작
6. 첫 교실: 반쯤 열린 문 "여긴…" / 빛바랜 학급 사진 "……왜 이렇게 익숙하지?" "여기… 내가 있었던 곳인가?" / 출석부: 한 이름만 빨간 줄, 옆 칸에 주인공 이름 "내 이름이… 왜 여기 있어?"
7. 첫 기억: 낙서·괴롭힘 기록 공책, 짧은 기억(놀리는 학생들, 주인공 목소리) "……방금 뭐였지?"
8. 학교 변화: 달아나는 학생, 칠판 "기억해.", 화장실 거울 "너는 기억하고 있어.", 옥상 기억 "……내가 한 건가?"
9. 교무실: 상담 기록, 가해 행동이 자신의 기억과 겹침, 주인공과 피해자가 함께 찍힌 사진
10. 과학실: 실험 기록, 퍼즐, 사고 기억 → "……내가 했어." → 피해자 귀신 등장(공격 X, 흔적을 보여줌)
11. 무당의 진짜 목적: 피해자 가족사진 속 무당 / 전화 "내가 널 학교로 보낸 이유가 궁금하겠지." "귀신을 떼어주려고 한 게 아니야." "네가 잊고 있던 것을 전부 기억하게 하려고 한 거야." / 부적 = 결계를 여는 장치
12. 최종 탈출 — 행동 선택: 증거·유품을 가지고 나감 / 증거를 없애고 혼자 탈출
13. 엔딩 1 불꽃 속의 교실 / 엔딩 2 끝나지 않는 괴롭힘 / 엔딩 3 고백 ("미안하다는 말로 끝낼 수 없는 걸 알아." "그래도 내가 한 일을 숨기지 않겠습니다.")

## 원본 공통 설정
- 탑뷰 이동, 쯔꾸르식
- 층 이동에 열쇠 필요
- 1층: 교무실, 주인공 반 교실, 기타 교실, 경비실(2층 열쇠)
- 2층: 과학실, 음악실, 컴퓨터실, 방송실
