# 에셋 제작 가이드

> 그래픽은 AI(Gemini, ChatGPT)로 만든다 (GDD 0장). 이 문서만 보고 어느 컴퓨터에서든 같은 그림체로 이어 만들 수 있게 정리한다.
> 마지막 갱신: 2026-10-17

---

## 1. 한눈에 보는 흐름

```
① AI로 그림 생성 (이 문서의 프롬프트 + docs/asset_reference.png 첨부)
        ↓  결과 이미지를 원본 그대로 저장
② assets/source/<영어이름>.png        ← Git에 올리지 않음 (용량)
        ↓  tools/sprites.json에 한 줄 추가
③ python tools/sprites.py              ← 잘라내기·배경 지우기·32px로 줄이기
        ↓
④ assets/sprites/<이름>.png + manifest.json  → 게임이 자동으로 사용 (Git에 올림)
```

- 그림 이름(키)은 게임 코드 이름과 같아야 한다. 예: `desk.png`, `locker_back.png` (영어 소문자, 한글 금지)
- 완성 그림이 없는 것은 게임이 `src/textures.js`의 **임시 그래픽**으로 그린다. 하나씩 바꿔 가도 된다.

### 다른 컴퓨터에서 처음 할 때
```bash
pip install pillow numpy
```
- `assets/source/`(원본)는 Git에 없다. 원본 없이 `python tools/sprites.py`를 실행해도 **이미 만든 PNG는 그대로 유지**되고, 새로 넣은 원본만 처리된다.
- 기존 에셋을 다시 가공해야 하면 원본을 USB·드라이브로 옮겨 와야 한다.

## 2. 그림 규칙 (가장 중요)

| 규칙 | 내용 |
|---|---|
| 시점 | **쯔꾸르(RPG Maker VX Ace/MV) 시점.** 바닥은 바로 위에서, 벽·가구는 **정면**에서 보고 윗면만 살짝 보인다. 비스듬한 아이소메트릭·원근 금지, 세로선은 세로로·가로선은 가로로 |
| 크기 | 한 칸 = 32×32. 키 큰 가구는 **32×64**(아래 칸이 바닥, 위 칸은 벽 앞으로 솟음). 생성할 때는 "도트 한 칸을 8×8 블록으로" 요청 (한 칸 = 256×256) |
| 그림체 | 도트 그림. 1픽셀 어두운 외곽선, 평평한 색 면, 안티에일리어싱·그라데이션·사진 같은 질감 금지 |
| 색 | 탁한 갈색, 차가운 청회색, 바랜 초록, 깊은 그림자. 빨강은 아주 드물게. **너무 밝지 않게** (밤의 폐교, 손전등) |
| 분위기 | 1980~90년대 시골 학교가 10년간 버려진 모습. 먼지, 바램, 낡음. 잔혹 묘사 없음 |
| 배경 | **마젠타(#FF00FF) 단색.** AI는 투명 배경을 잘 못 만든다. 마젠타는 도구가 지운다 |
| 금지 | 글자·숫자·치수선·테두리·미리보기 격자선. (워터마크 반짝이는 도구가 지우거나 잘라낸다) |

### 방향 규칙 (가구가 붙은 벽에 따라 보이는 면이 다르다)

| 놓인 곳 | 보이는 모습 | 예 |
|---|---|---|
| **위쪽 벽** 앞 | 앞면 (문·손잡이·서랍) | 교실·복도 사물함, 칠판, 약품장 |
| **아래쪽 벽** 앞 | **뒷면 + 지붕**(윗면이 넓게 보임) | 경비실·교무실 사물함 → `locker_back` |
| 방 가운데 | 앞면 + 윗면 (책상처럼 위가 잘 보이게) | 책상, 실험대 |
| 바닥 소품 | 위에서 본 작은 물건, 칸 가운데 | 가방, 공, 명찰 |

- 사물함은 게임이 자동으로 앞·뒤를 고른다 (아래쪽 벽에 붙으면 `locker_back`).
- 문은 정면 그림 한 종류. 도구가 **문틀·문턱**을 둘러 벽과 구분한다.

### 게임이 자동으로 해 주는 것
- **벽:** `wall_face`(앞면)·`wall_top`(윗면)을 위치와 지금 있는 방에 따라 골라 깐다.
- **바닥 변형:** `floor_xxx_2.png`, `floor_xxx_3.png`가 있으면 약 18% 칸에 섞어 깐다 (매번 같은 자리).
- **2칸 가구:** 그림 높이가 64면 바닥 칸 기준으로 위로 솟게 그리고, 앞뒤 가림을 맞춘다.
- **방 단위 시야, 난간(`rail_h`), 문 너머 바닥.**

## 3. 프롬프트 쓰는 법

### 3-1. 새 대화를 시작할 때 (그림체 고정) — 매번 첫 메시지
첨부: **`docs/asset_reference.png`** (지금까지 완성한 에셋 모음)
```
I am making pixel art assets for a Korean horror adventure game in classic RPG Maker VX Ace / MV style. The attached sheet shows finished assets: match this style exactly (palette, outline, pixel size, mood) in everything you make in this chat.
Rules for every image:
- Camera: floors seen from directly above; walls and furniture seen straight from the front with only a thin sliver of their top. No isometric angle, no perspective, all edges perfectly vertical or horizontal. Light from the top-left.
- Setting: a rural Korean high school from the 1980s-90s, abandoned for ten years, at night. Dusty, faded, worn, not too bright.
- One game tile is 32x32 pixels; draw each art pixel as a clean 8x8 block (one tile = 256x256). Tall furniture is 32x64.
- Clean 1-pixel dark outlines, flat colors, no anti-aliasing, no gradients, no photographic texture.
- Flat magenta #FF00FF background, each item in its own cell with gaps. No text, labels, numbers, measurement lines, frames or grid lines.
Reply "OK" and wait for my requests.
```
이후에는 같은 대화창에서 **"Same style as before."로 시작하는 짧은 요청**만 보낸다 (한도 절약).

### 3-3. 자주 생기는 문제와 고칠 문장

| 문제 | 덧붙일 문장 |
|---|---|
| 비스듬하게(아이소메트릭) 나옴 | `NOT isometric. Seen straight from the front, all edges perfectly vertical or horizontal.` |
| 물건 밑에 바닥·벽까지 그림 | `Draw ONLY the object, no floor or wall behind it, flat magenta around it.` |
| 타일 가장자리에 띠·선 → 이으면 줄무늬 | `Remove the band/line along the [top/bottom] edge; the pattern must continue to every edge.` |
| 미리보기에 격자선 | `No grid lines in the preview; it must look like one continuous floor.` |
| 사진 같은 질감 | `Redraw as PIXEL ART like the attached assets: flat colors, 1-pixel outlines, no photographic texture.` |
| 한 칸에 디테일이 너무 많아 줄이면 뭉개짐 | `Bigger, simpler shapes; it must stay readable at 32x32.` (계단은 한 칸에 2단) |
| 변형 타일 색이 기본과 다름 | 기본 타일을 첨부하고 `Use EXACTLY the attached tile as the base.` — 그래도 다르면 **데칼(4-1)로 대신** |
| 너무 밝음 | `Darker and dustier, abandoned school at night.` |
| 크기 비율이 틀림 (문이 옆으로 김 등) | `The whole object must fit a square 32x32 (or 32x64) cell.` |

### 3-4. 한도 아끼기
- 같은 대화창에서 이어 요청한다 (스타일을 다시 설명하지 않아도 됨).
- 한 장에 4~6개를 묶어 받는다. 미리보기(4×4 반복)는 필요한 바닥 타일에만.
- Gemini 한도가 차면 다음 날 초기화. 그 사이엔 ChatGPT에서 3-1부터 시작한다.

## 5. 원본을 게임용으로 바꾸기 (`tools/sprites.py`)

1. 결과 이미지를 `assets/source/`에 영어 이름으로 저장한다. 예: `classroom.png`
2. 그림들의 영역(좌표)을 찾는다.
   ```bash
   python tools/sprites.py --boxes assets/source/classroom.png
   ```
   출력된 `"box": [x0, y0, x1, y1]`이 왼쪽 위부터 그림 하나씩이다.
3. `tools/sprites.json`에 키마다 한 줄 추가한다.
   ```json
   "desk":    { "src": "classroom.png", "box": [20, 30, 260, 270], "mode": "object" },
   "board":   { "src": "classroom.png", "box": [300, 30, 540, 510], "mode": "object", "size": [32, 64] },
   "floor_roof": { "src": "roof.png", "box": [20, 16, 504, 504] }
   ```
4. 실행한다. 게임을 새로고침하면 바로 바뀐다.
   ```bash
   python tools/sprites.py
   ```
5. 결과 확인: `assets/source/_preview.png`(4배 모음), 그리고 게임 화면 (`python tools/serve.py` → `/?dev`).

### 설정 항목
| 항목 | 쓰임 |
|---|---|
| `mode: "tile"` (기본) | 바닥·벽. 영역을 꽉 채워 줄인다. 가장자리 4px는 자동으로 잘라 마젠타 번짐을 없앤다 |
| `mode: "stretch"` | 문처럼 비율이 달라도 칸에 꽉 맞춘다 |
| `mode: "object"` | 가구·소품. 마젠타를 지우고 비율을 지켜 칸 아래 가운데에 놓는다 |
| `size: [w, h]` | 결과 크기 (기본 32×32, 키 큰 가구 32×64, 사물함은 30×54로 줄여 씀) |
| `existing: true` | `assets/sprites/<키>.png`를 수정하지 않고 `size`를 manifest에 등록. Boot가 메모리에서 표시 크기를 맞춘다. `src`·`box`는 불필요 (난간·책상·칠판·창문·그을음) |
| `fill: true` | object를 비율 무시하고 size에 꽉 채운다 |
| `scale: 0.8` | object를 칸보다 작게 (바닥 소품) |
| `brighten: 1.7` | tile·stretch 결과를 밝게 (밝기 곱). 문틀(`frame`)은 그 뒤에 둘러서 그대로 — `homedoor` |
| `parts` | 여러 조각을 따로 잘라 한 장에 배치: `[{"box": [...], "at": [x, y, w, h]}]`. 조각은 비율을 지켜 at 영역 아래 가운데에 놓인다 (`mirror`: 거울은 벽 칸 아래쪽, 세면대는 바로 아래) |
| `trim: [l, t, r, b]` | 영역을 더 잘라낸다 (예: 아래쪽 띠 제거 `[0, 0, 0, 40]`) |
| `patch: [[x, y, w, h, dx, dy]]` | (x,y,w,h)를 (dx,dy)만큼 떨어진 곳에서 복사해 덮는다 (워터마크 지우기) |
| `cutout` | 물건 밑에 바닥까지 그려졌을 때 떼어 내기: `{"kind": "border", "tol": 55}` 또는 `{"kind": "blue"}`. 배경이 회색 격자일 때는 `{"kind": "flood", "tol": 60}` — 바깥과 이어진 배경만 지워 가구 다리 사이도 빈다. `"extra": [[r, g, b]]`로 그림 뒤 벽판 같은 색을 함께 지운다 (2층 `console`·`tapedeck`) |
| `frame: true` | 문틀·문턱 두르기 (문) |
| `clear_dark: [x0, y0, x1, y1, 밝기]` | 범위 안 어두운 픽셀을 투명하게 (열린 문 너머로 바닥이 보이게) |

### 새 종류의 그림을 넣을 때
- **이미 게임에 있는 이름**(위 4장 목록)은 PNG만 생기면 자동으로 바뀐다.
- **새 이름**(데칼, 장판, 새 가구 등)은 맵(`data/maps/*.json`)이나 코드 연결이 필요하다. Claude에게 요청한다.
