# 잊힌 교실 (가제)

반복되는 학교 악몽 끝에 폐교를 찾아간 주인공이, 단서를 추리해 스스로 외면했던 기억을 되찾는 쯔꾸르식 공포 퍼즐 웹 게임.

> 이 게임은 학교폭력과 죽음을 소재로 합니다.

## 실행

```bash
python tools/serve.py
```

브라우저에서 http://localhost:8123 접속. (빌드 과정 없음 · Phaser 3 CDN 사용)

테스트할 때는 http://localhost:8123/?dev 로 원하는 시점부터 시작할 수 있습니다. → [개발자 모드](docs/개발자_모드.md)

## 조작

| 키 | 기능 |
|---|---|
| WASD / 방향키 | 이동 |
| E / Space | 조사 · 대화 넘기기 |
| ESC | 기억 노트 |

## 현재 상태

프롤로그 + 1장 데모. 그래픽·사운드는 임시본입니다.
