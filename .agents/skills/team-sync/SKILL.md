# 작업 준비

먼저 저장소 루트의 `.agents/skills/team-common.md`를 읽는다.

1. 계정·origin·개인 브랜치와 담당 이슈·열린 개인 PR을 확인한다. 제출한 PR이 열려 있으면 새 작업 대신 기존 작업을 이어가도록 안내하되 동기화 자체는 가능하다.
2. 공통 안전한 동기화와 충돌 해결 절차를 실행한다. 미커밋 변경은 자동 저장/삭제하지 않는다. 개인 브랜치에 origin/main을 반영한다. 로컬 main 자체를 수정할 필요는 없다.
3. 이전 PR 병합 후 변경이 다음 PR에 다시 나타나는지 merge-base와 diff로 확인한다. squash/rebase 병합 등으로 중복 변경이 남았다면 새 작업 전에 선생님에게 개인 브랜치 정리를 요청하고 임의 reset하지 않는다.
4. 브랜치·main SHA·검증 결과와 “할 일 보여줘”를 안내한다. 실패 시 실패 단계와 보존된 변경을 보고한다. 이 스킬은 push하지 않는다.
